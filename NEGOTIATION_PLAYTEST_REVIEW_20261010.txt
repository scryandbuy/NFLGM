Controlled comparisons using the save's actual assets
----------------------------------------------------
audit_negotiation_playtest.py reads a copy into memory and prices identical
packages before/after persuasion. It does not write the source save. At the end,
one separate controlled trade is executed in that disposable memory only.

280 player-package comparisons: two actual targets each from BAL, BUF, MIN, SF,
35 single/two-pick packages per target. Patient BAL/MIN granted concessions;
BUF/SF declined that pitch. Core players still listened; cap-invalid star deals
remained blocked. None of these 280 packages crossed the preview acceptance
boundary. This sample used high/low roster endpoints, so it does not establish
that player concessions are too weak or cannot matter in a close deal.

96 deliberately selected close pick packages: four first/second-round targets
each for BAL/MIN, 12 nearby owned-pick packages per target. 56 crossed the preview
acceptance boundary after the correction, zero moved the wrong way. This sample
is intentionally concentrated around the boundary; 56/96 is NOT a league-wide
success rate. An owned BAL first's quote moved from 37.145 to 36.12249 trade-value
units, about 2.75%. Its identical GB-first return went from short to fair. The
actual Propose path then accepted and transferred the picks, still in week 6.
CPU financial/portfolio checks were active, not stubbed. Preview comparisons
left transaction count and session RNG unchanged before that separate execution.

Player personality, counters and memory
--------------------------------------
Six fixed-profile contract scenarios, same player/ask/offer otherwise:
repeating an offer 1% below the counter did not buy a discount. Max-money was
final on counter two; the other five reached final on counter three. The first
counter was never final. This is the current explicit game abstraction; the
playtest does not establish that every personality should use this cadence.

Changing the package with a no-trade commitment earned acceptance at 2% below
the standing counter in each controlled profile. Its total value differed:
homebody's acceptable price changed 21.69 -> 20.45; max-money 21.70 -> 21.05.
Reducing trust to .4 weakened those concessions to 21.20 and 21.44 respectively.
These are million-per-year figures for synthetic otherwise-identical extension
fixtures; not quotes or deals observed in the user's career.

Repeated choices/subject swapping cannot stack a concession. Closed GM calls
survive save/reload; a new week opens a new window. Existing player promises and
trust persist. Long-term GM-to-GM relationship memory is still not implemented;
this pass did not silently add a new relationship model or treat each week's
fresh conversation as evidence of a lifetime reputation system.
