Portable export improvement
Session.export_chunks yields lossless gzip blocks directly to the browser.
Compression uses level 9 and fast record-level JSON encoding. Transfers are
chunked; no full-save string crosses the Python/JavaScript bridge and no second
compressed MEMFS file is retained. Individual JSON records may exceed a transfer
chunk; this is not a claim of a hard global memory bound. A modal progress view
pauses game actions and autosave snapshots during export, yields to painting,
cleans up generators/proxies, resumes pending autosaves/routes, and reports errors.
Native export_file consumes the same generator. Legacy JSON and gzip imports work.
This does not delete history or incorporate the unfinished development overhaul.
