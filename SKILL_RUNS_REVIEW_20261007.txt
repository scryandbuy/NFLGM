Occasional receiver and fullback handoffs

Football rationale: Give the existing eleven an occasional changeup when the situation and public running skills fit. A fast receiver can threaten the perimeter, especially in an offense already calling motion; a capable fullback can take a short-yardage inside handoff. Losing an ordinary HB carry and the selected runner's block are real tradeoffs. Strong runners receive more opportunities, without mandatory touches. No roster changes or hidden potential are involved.

Implementation: skill_runs.choose executes on the selected field unit inside the run resolver. WR jet sweeps (motion) and end-arounds (no motion) use existing outside-zone/stretch blocking; FB handoffs use inside-zone/power/duo/trap. WR calls require early downs, 3-12 yards to go, and more than 10 yards of field. FB calls require <=2 yards to go and a real FB assigned that on-field role. Neither replaces a sneak, designed QB run, pass, protect-ball call, or final-two-minute snap. No HB means no gadget fallback. HB lead blocks can now support another carrier; every carrier remains excluded from his own blocking reps. Existing actual-carrier stats, contact/fumble lookup and ticker carry the selected identity. Build manifest includes the new module and all changed engine sources are mirrored.

Observed saved-game results: None; no existing save was modified or used to claim season balance.

Controlled evidence: New tests run naturally selected WR/FB handoffs through the full play resolver, stat book, fumble lookup and ticker. A controlled drive test uses the actual selected personnel and run resolver, forcing only the carrier choice to ensure integration coverage. Negative cases cover no WR/FB/HB, QB runs, sneaks, passes, third/fourth-down receiver restraint, protected ball, late clock and incompatible scheme. Existing run execution, support and QB run tests remain passing.

Selection experiment: 10,000 eligible outside calls, fixed seed718, one on-field WR, all WR_RUN attributes45: 21 end-arounds without motion,34 jet sweeps with motion. Attributes90:319/693. Same seed and 10,000 eligible second-and-one power calls: FB_RUN attributes55 yielded148 FB handoffs;85 yielded1266. These conditional rates are not rates across all game snaps.

Effectiveness diagnostic: 2,000 identical seeded play resolutions per carrier/quality cell, synthetic 22 personnel versus 4-3 over box6, midfield60. Forced carrier only, every actual YAC carrier attribute explicitly55 or85; ordinary blockers and defenders unchanged. Outside WR YPC3.71/7.66 versus HB3.71/7.67. Inside power FB3.69/7.61 versus HB3.69/7.61. Stuff rates about7.9%-8.7%. This establishes no extra success bonus for the new carrier labels; actual running skills still determine outcomes. It does not establish realistic league-wide rates.

Remaining uncertainty: Existing run resolution abstracts lane geometry; receiver actions use existing outside blocking, not simulated jet timing or reverse exchange geometry. Motion propensity and scheme preference distinguish coaches through the existing call, without a separate gadget-slider. Season-level frequency, individual touch distribution and outcomes on real rosters remain balance checks. No full-verification claim is made.

Review corrections: selection uses serialized accel_rating and truck_rating, with attribute sensitivity regression. The strongest eligible runner determines one call chance; eligible runners share that chance by fit. One, three and four equally strong on-field WRs each produced693 selections/10,000 controlled eligible calls, avoiding an artificial receiver-count multiplier.
