Missing defensive touchdowns: confirmed separate limitation
---------------------------------------------------------
Interception endpoints are clamped to the field before a return can score.
Lost fumbles have no defensive return model. Neither was changed here.
nflverse 2021-25 regular-season play-by-play (excluding no_play, punt and
kickoff returns) contains 180 interception TDs and 86 lost-fumble TDs:
266 / 1,359 = .196 defensive TDs per game.
Subtracting seven points per such TD from final scores reduces 17+ margins
from 26.122% to 24.209%. That 1.91-point difference is an arithmetic sensitivity,
NOT a simulated counterfactual; possession and later decisions would differ.
It explains only part of the roughly 11-point franchise discrepancy.
Sources: https://github.com/nflverse/nflverse-data/releases/tag/pbp
         https://nflreadr.nflverse.com/articles/dictionary_player_stats_def.html
Selected research rows and calculations are retained in outputs/margin-real-pbp.

Two isolated behavior defects
-----------------------------
1. Coverage score direction (2b4d240): game -> season caller -> schemes ->
   coverage_call all pass offense-minus-defense score. pick_job incorrectly
   used positive score to select late lead-protection coverage. Now negative
   offense score selects that job. Early-game and third-down priorities stay.
   Three deterministic tests include the actual season caller integration.
2. Duplicate late-lead third-and-long run bias: schemes.pass_rate already combines score,
   clock, down and distance. game.py additionally supplied -3.5 or -1.0 bias;
   its x4 log-odds conversion overwhelmed the table. Up seven, third-and-eight,
   180 seconds, 11 personnel: 74.37% became 5.05%. The separate correction
   changes the third-and-six-or-more lean from -1 to zero. All other late-
   leading downs retain -3.5. Saved coach preferences still apply, and urgent
   trailing drills/backed-up final-minute behavior remain intact. Four
   deterministic drive/caller tests cover these obligations.

   A broader removal was tested and rejected: it raised holdout scoring and
   drives, and the real conditional first-down rates do not support it.
   NFL 2021-25 REG, last four minutes, leading, run/pass plays only, excluding
   kneels/spikes and the own-20 final-minute special case:
   first-down dropbacks 6.22% (1,367 snaps); third-and6+ 50.15% (664 snaps).
   Third-and6+ by lead: 1-8 points 64.44% (374); 9-16 31.48% (162);
   17+ 32.03% (128). The broad removal's ~25% first-down prediction is not
   appropriate to this specific situation. Raw counts retained in
   outputs/real-late-lead-rates.json, from the same nflverse PBP source.

Defensive return TD implementation judgment
------------------------------------------
Defer to a separate correctness change. Existing defensive-touchdown scoring,
try, kickoff and OT plumbing can be reused, but this still needs return endpoint
resolution, real carrier/recoverer attribution, penalty acceptance/enforcement,
EPA and defensive statistics, ticker/replay and save/load tests. Interception
touchbacks/pick-sixes should be implemented and tested first, then lost-fumble
returns; nullifying and post-play penalties, final-play scores, OT walkoffs and
correct next-possession ownership are required gates. Current completed-pass
fumble carrier selection uses offense.wr[0], which must not be carried forward
as the return model's attribution. No return-TD source changes were made here.
