Fit 2021-24, hold out 2025. Stop rates by recovery region; positive distance

Runner versus fastest four pursuers' speed/acceleration changes distance scale

Engine/reporting contract
Keep original type (interception, run, complete, sack, scramble) and offensive
yards. Add return_kind, returner, ret, return_start, end_spot, touchback,
defensive_td; fumbles also add recoverer/fumble_recovered_by/fumble_forced.
TD events set touchdown=True and scoring_side='defense'. Coordinates are the
original offense's distance to the opposing goal, so defensive TD ends at100.
An end-zone touchback transfers at old coordinate20 (new offense own20).
Return yardage excludes travel inside the returner's own end zone.
dr.result='Defensive touchdown'; points=-6 plus defending team's try. OT return
TD ends immediately without a try. Existing defensive-TD kickoff path sends
the ball back to the team that conceded it.

Stats: int_ret_yds/int_ret_td, fum_rec/fum_ret_yds/fum_ret_td, def_td.
Retain normal interception/fumble counts and pre-fumble offensive gain.
Do not credit an offensive passing, receiving or rushing TD for a return TD.
EPA recognizes defensive scoring before examining the general touchdown flag.
Resolve loose-ball outcomes before choosing enforcement; accepted live fouls
can cancel the turnover and stats. Post-return fouls move the new possession;
post-score fouls affect the defending team's try. Return yards exclude penalty
yardage. Fumbles identify the actual selected receiver/carrier and fielded
recoverer, rather than roster WR1/HB1. Unforced fumbles do not credit an FF.

Validation
16 new tests: scoring/stat ownership, touchbacks/end-zone exit, distance-based
scores, returner/recovery stats, actual receiver fumbles, strip-sack end-zone
recovery, live penalty cancellation, offensive foul declined, post-return and
post-TD enforcement, OT walkoff/no try, capped legacy returns, EPA and RNG
restore determinism. The combined run passed116 tests before the last three
targeted cases; all16 new cases then passed (119 distinct passing tests).
Combined coverage includes actual Session save/load/live-journal replay,
previous game/penalty/clock fixes, fourth-down routes and Game Plan wiring.

Boundaries
No new return-phase penalty lottery, lateral/re-fumble chain or backward-return
safety model. Existing live and post-play penalties are enforced. Recovery is
at the current modeled end of the offensive play, without a separate loose-ball
bounce simulation. Main integration owns display/reporting and the subsequent
three-season scoring study. No source changes to session/UI/report modules.
